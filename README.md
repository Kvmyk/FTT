# Find My Throne 🚻
## Opis

**Find My Throne** to aplikacja, która pomoże Ci szybko znaleźć najbliższą toaletę publiczną! 🚽 Niezależnie od tego, gdzie się znajdujesz, nasza aplikacja wskaże Ci najszybszą drogę do miejsca, gdzie możesz skorzystać z toalety.

## Funkcje

- **Lokalizacja najbliższych toalet** 🗺️  
  Aplikacja wykorzystuje Twoją bieżącą lokalizację, aby znaleźć najbliższe toalety publiczne.

- **Nawigacja w czasie rzeczywistym** 🧭  
  Otrzymuj wskazówki krok po kroku, aby szybko dotrzeć do wybranego miejsca.

- **Informacje o udogodnieniach** ℹ️  
  Sprawdź, czy toaleta jest dostosowana do potrzeb osób niepełnosprawnych, czy posiada przewijak dla niemowląt itp.

- **Oceny i recenzje użytkowników** ⭐  
  Przeczytaj opinie innych użytkowników i dodaj własną ocenę po skorzystaniu z toalety.
